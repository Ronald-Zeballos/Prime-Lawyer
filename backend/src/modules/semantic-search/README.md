Semantic search module for the open LegalTech platform.

Current MVP responsibilities:
- recover similar cases using case metadata plus OCR text from related documents
- recover similar documents using original file names, OCR text and process type
- expose heuristic retrieval before embeddings exist
- expose application services for legal-ai contextual retrieval

Later responsibilities:
- prepare searchable chunks from closed cases and OCR text
- support semantic retrieval with embeddings in later phases
